# PHP8.2

## 動的プロパティが非推奨になった

- PHP8.2 からクラスで宣言されていないプロパティをオブジェクトに動的に追加すると、非推奨の警告が発生する仕様に変更された
- PHP9では完全にエラーとなる予定
- 次の例では `name` がクラスに宣言されていないため、代入時に警告が出る

```php
class User {}

$user = new User();

// 動的プロパティの作成
// nameというプロパティはUserにはないのに追加できる
// ほとんどの多言語だとそもそもエラー
$user->name = 'Taro';  // Deprecated
```

- プロパティはクラス内であらかじめ宣言する必要性が生じた
- 任意のプロパティを受け入れる必要がある場合は、セッターやゲッターを実装する
- PHP9になるまでならば、 `#[AllowDynamicProperties]` 属性を付与すれば、そのクラスと子クラスでは動的プロパティの非推奨警告が出力されない

```php
// クラス内にプロパティを宣言（まあ、普通だが...）
class User {
    public string $name;
}
```
